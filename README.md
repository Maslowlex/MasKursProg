# Система мониторинга скорости перемешивания

## Постановка задачи
Программа предназначена для мониторинга технологического процесса в химическом реакторе по параметру «скорость перемешивания» (X). Программа преобразует измеряемые значения в нормированный показатель качества Q(X), проводит оперативный контроль состояния процесса и статистический анализ выборки.

### Входные данные:
*   Параметр X: скорость перемешивания, измеряется в об/мин.
*   Диапазон X: от 100 до 900 об/мин.
*   Нормальное состояние: штатный режим: 350–650 об/мин.
*   Количество измерений в выборке: N = 70.

### Формула преобразования Q(X):
$$Q(X) = 
\begin{cases}
2(X-350)+5, & \text{при } X < 350 \\
0.5(X-500)^2+45, &  \text{при } 350 \le X \le  650 \\
2\ln(X-650+2)+60, & \text{при } X > 650
\end{cases}$$


### Ручной расчет (Примеры):
1. X = 300 (меньше 350): Q = 2*(300 - 350) + 5 = -100 + 5 = -95,00
2. X = 425 (в диапазоне 350-650): Q = 0.5*(425 - 500)^2 + 45 = 2857,50
3. X = 700 (больше 650): Q = 2*ln(700 - 650 + 2) + 60 = 2*ln(52) + 60 ≈ 2*3.951 + 60 ≈ 67,90
   
**Ограничения и примечания:**
* Для третьей ветви (при \(X > 650\)) аргумент логарифма равен \(X - 648\). Для корректной работы логарифма необходимо, чтобы \(X - 648 > 0\), то есть \(X > 648\). Так как по условию задачи \(X\) находится в диапазоне от 100 до 900, это ограничение выполняется для всех допустимых значений \(X > 650\).
* При \(X < 347.5\) значение \(Q\) становится отрицательным. Это следует учитывать при физической интерпретации показателя качества.

**1. Нормальное значение (\(X = 500\))**
Ожидаемый результат: попадание в диапазон нормы.

$$
Q(500) = 0.5 \cdot (500 - 500)^2 + 45 = 0.5 \cdot 0 + 45 = 45.00
$$

$$
\text{Отклонение} = \frac{|Q - Q_0|}{Q_0} \cdot 100\% = \frac{|45.00 - 45.0|}{45.0} \cdot 100\% = 0.00\%
$$

Состояние: **НОРМА**.

**2. Граничное значение (\(X = 502.68\))**
Значение подобрано близко к верхней границе допустимого диапазона (8% от \(Q_0\), то есть до \(48.6\)).

$$
Q(502.68) = 0.5 \cdot (502.68 - 500)^2 + 45 = 0.5 \cdot (2.68)^2 + 45 = 0.5 \cdot 7.1824 + 45 \approx 48.5912
$$

$$
\text{Отклонение} = \frac{|Q - Q_0|}{Q_0} \cdot 100\% = \frac{|48.5912 - 45.0|}{45.0} \cdot 100\% \approx 7.98\%
$$

Так как \(7.98\% \le 8\%\), состояние: **НОРМА**.

**3. Нарушение границы / Тревога (\(X = 506\))**
Значение превышает допустимый порог в 20% (когда система переходит в статус «Тревога»).

$$
Q(506) = 0.5 \cdot (506 - 500)^2 + 45 = 0.5 \cdot (6)^2 + 45 = 0.5 \cdot 36 + 45 = 18 + 45 = 63.00
$$

$$
\text{Отклонение} = \frac{|Q - Q_0|}{Q_0} \cdot 100\% = \frac{|63.00 - 45.0|}{45.0} \cdot 100\% = \frac{18.0}{45.0} \cdot 100\% = 40.00\%
$$

Так как \(40.00\% > 20\%\), состояние: **ТРЕВОГА**.
